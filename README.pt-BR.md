# HashMC Platform

Plataforma da rede HashMC para as versões modernas do Minecraft.

Sucessora do [`server-plugin`](https://github.com/hashmc-network/server-plugin), que fica como legado da rede 1.8.8.

## Estado atual

Projeto em início de desenvolvimento. Ainda não há build, módulos ou CI.

A arquitetura planejada está documentada em [docs/](docs/README.pt-BR.md#arquitetura): a [rede](docs/architecture/network/README.pt-BR.md), a [persistência](docs/architecture/persistence/README.pt-BR.md), a [mensageria](docs/architecture/messaging/README.pt-BR.md), o [motor de jogo](docs/architecture/game-engine/README.pt-BR.md), a [segurança](docs/architecture/security/README.pt-BR.md) e a [observabilidade](docs/architecture/observability/README.pt-BR.md).
